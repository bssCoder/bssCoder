## 🌟 Projects

### 1. UAP - Unified Access Platform  
**Tech Stack:** React.js, Node.js, Express.js, MongoDB, Tailwind CSS, Redux, JWT, OAuth 2.0, bcrypt  
**Description:** UAP is a Single Sign-On (SSO) platform that centralizes authentication across multiple apps. With MFA, RBAC, secure sessions, and detailed activity logs, it simplifies enterprise-grade access while enhancing security.  
- **Features:**  
  - Secure SSO & OAuth 2.0 support  
  - Email-based Multi-Factor Authentication (MFA)  
  - Role-Based Access Control (RBAC) for admins  
  - Real-time login history tracking  
  - Multi-tenant support and org-level settings  
- **Source code available on GitHub:** [UAP Repository](https://github.com/bssCoder/UAP)  

### 2. MindMeld – Cognitive Performance Tracker  
**Tech Stack:** React.js, Node.js, Express.js, MongoDB, Chart.js, Tailwind CSS, JWT, Redux, Cloudinary  
**Description:** MindMeld is a dynamic web application that helps users track and visualize their cognitive performance over time. By combining psychology with intuitive UI and clean data insights, it empowers users to optimize focus, memory, and mental clarity.  
- **Features:**  
  - Daily self-assessment for cognitive parameters  
  - Interactive charts and insights using Chart.js  
  - Profile management with authentication and data persistence  
  - Aesthetic, minimalist UI inspired by modern neuro-aesthetic design principles  
- **Use Case:** Ideal for students, professionals, or anyone aiming to understand and enhance their mental performance over time.  
- **Source code available on GitHub:** [MindMeld Repository](https://github.com/bssCoder/MindMeld)
